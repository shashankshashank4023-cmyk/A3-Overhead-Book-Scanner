Windows desktop project · Python · OpenCV

A3 Overhead Book Scanner

Digitise A3 registers and book spreads with a UVC webcam or existing image files. Capture pages, correct perspective, enhance images, split spreads and export multi-page PDFs.

View source on GitHubBuilds & test results

What the application does

Camera capture

Requests 3840×2160 MJPG where supported and reports the camera's negotiated resolution.

Page correction

Detects a plausible page quadrilateral and applies perspective correction, with a safe frame fallback.

Image enhancement

Document, colour and grayscale processing modes.

Book spreads

Optional left/right split for landscape two-page captures.

PDF export

Save captured pages as a multi-page PDF or preserve a session with a JSON manifest.

Windows build

GitHub Actions runs tests and creates a downloadable Windows build artifact.

Run on Windows 10/11

  1. Install 64-bit Python 3.10–3.12 and connect a UVC-compatible webcam.
  2. Download or clone the repository.
  3. Run run_windows.bat to install dependencies and launch the app.
  4. Choose Start Camera or Open Image Folder; press Space to capture.
  5. Use Export PDF to save a document.

The desktop scanner does not run inside this website. This page is a project overview and download/CI portal.

Hardware validation note

A 4K capture request does not guarantee a 4K stream. Actual resolution, frame rate, focus, lighting and page-detection quality must be checked with the target webcam and Windows PC. This prototype does not provide OCR or searchable PDFs.
